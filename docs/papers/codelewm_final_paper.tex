\begin{abstract}
We study whether a JEPA-style latent code world-model can rerank candidate
program edits without executing them, scoring candidates by predicted latent
transitions rather than by generating patches. We release \modelname{}, a
manifest-backed research artifact: a $\sim$45M-parameter transition model with
an EMA target encoder and LeJEPA-family SIGReg anti-collapse. We evaluate it
under a \emph{configuration-bound}, control-first claim gate: the acceptance
thresholds and the no-action, lexical, and shuffled-action controls are fixed in
the training configuration before launch, and a machine-readable gate decides
which claims may open. The outcome is one falsified hypothesis, non-collapsed
diagnostic signals, and a single narrow downstream win that does not open an
aggregate claim. The original commit-edit action-use hypothesis is negative: on
$1{,}000$ held-out retrieval examples, commit-edit text-action ranking
(Recall@1 $0.263$, MRR $0.370$) loses to a no-action baseline ($0.441$,
$0.533$). A separate execution-trace substrate is cleaner diagnostically:
execution retrieval beats every control (Recall@1 $0.254$/$0.273$ vs.\ all
controls below $0.024$), and single-point mutation surprise reaches AUC $1.0$
over $260$ scored pairs. These are training-health signals, not downstream
utility. The only open downstream slice is HumanEval WS-D, a deterministic
mutation-distractor reranking pack of $n=47$ problems: \modelname{} reaches
$46/47$ ($0.979$) on both seeds, beating the strongest non-trivial control,
shuffled-action ($0.894$/$0.915$), by $+8.5$ and $+6.4$ points (4 and 3
problems; 95\% bootstrap CIs $[0.0,19.1]$ and $[0.0,14.9]$ that \emph{include}
zero), and the no-action control by $+10.6$ and $+8.5$ points. The two seeds are
a training-stability check on the same $47$ problems, not independent
replications. The aggregate model-quality claim stays closed: MBPP-Plus WS-D is
saturated on its $17$ problems because \modelname{}, no-action, and lexical all
reach $17/17$, so the slice has zero headroom and is non-informative for any
lift. Representation probes do not beat controls, broad semantic surprise has no
scorable pairs, and the downstream rows expose no standalone \code{p\_pass}
score. We therefore present \modelname{} as a reproducible
negative-and-diagnostic study with one narrow positive slice, not as evidence
that the model generally improves coding, together with a released
anti-saturation falsification harness whose gate is deliberately still closed.
The main contribution is a reproducible artifact and a falsification protocol:
code-world-model reranking claims need no-action, lexical, and shuffled-action
controls and configuration-bound gates because many apparent wins vanish under
those controls.
\end{abstract}

\section{Introduction}

World models are appealing for code because code edits have a natural
transition structure: a before-state, an action or instruction, and an
after-state. If a model can learn that transition, it may be useful even when
it is not a code generator. A latent scorer could rank candidate patches
produced by humans, search, or large language models, while keeping candidate
code untrusted and avoiding execution in the scoring path.

Joint-embedding predictive architectures (JEPAs) learn by predicting future
latents rather than reconstructing observations
\citep{assran2023selfsupervisedlearningimagesjointembedding,bardes2024revisitingfeaturepredictionlearning}.
LeWorldModel studies stable end-to-end JEPA-style world modeling from pixels
\citep{maes2026leworldmodelstableendtoendjointembedding}. \modelname{} asks
whether the same idea can be made credible for code edits. The transition
contract is:
\begin{equation}
\label{eq:contract}
  \hat z_{\mathrm{after}} =
  P(E(s_{\mathrm{before}}), A(a)).
\end{equation}
The intended downstream use is ranking, not generation: given a before-state,
an edit or execution action, and candidate after-states, score which candidate
best matches the learned transition.

This paper reports the full evidence arc instead of selecting only the
strongest slice. The early commit-message-conditioned substrate fails the
action-use gate. A later execution-trace substrate repairs collapse and
produces useful diagnostics. The final v0.9/v1.0 downstream replay shows a
narrow HumanEval WS-D win but closes the aggregate claim because MBPP-Plus is
solved by controls. We frame the result as an artifact-backed negative study:
the system makes the tested hypothesis falsifiable, identifies where the model
fails, isolates a narrow positive slice, and turns the failure modes into
concrete next research requirements.

\paragraph{Research questions.}
\begin{enumerate}[leftmargin=1.5em]
  \item \textbf{RQ1: Does action conditioning improve code-transition
  retrieval on commit-edit data?} No. The v0.2 action-swap intervention loses
  to no-action on the headline retrieval gate.
  \item \textbf{RQ2: Can an execution-trace substrate support non-collapsed
  learned diagnostics?} Yes, in the narrow diagnostic sense. v0.9 retrieval
  beats retrieval controls, and mutation surprise AUC is 1.0 on both seeds.
  \item \textbf{RQ3: Does the learned world model improve downstream candidate
  reranking?} Partially. HumanEval WS-D improves over no-action on two seeds,
  but MBPP-Plus is saturated by no-action and lexical controls, so the
  aggregate downstream claim is closed.
\end{enumerate}

\paragraph{Contributions.}
\begin{enumerate}[leftmargin=1.5em]
  \item A \emph{configuration-bound, control-first claim-gate methodology} for
  code-world-model reranking: falsification gates (no-action, lexical,
  shuffled-action, and LLM-order controls; collapse, retrieval, surprise, and
  downstream-lift thresholds with two required seeds) are fixed in the training
  configuration before any run and enforced as a machine-readable artifact
  contract, so that apparent wins that vanish under controls are caught
  automatically rather than reported.
  \item A reproducible code world-model artifact instantiating this methodology,
  with dataset construction, training, retrieval, surprise, latent-probe,
  downstream reranking, paper-demo replay, manifests, checksums, and secret scans.
  \item A negative action-use result showing that commit-edit action text does
  not beat a no-action baseline under the tested intervention, and a diagnostic
  execution-substrate study showing non-collapse, retrieval lift over controls,
  and mutation-surprise separation without overstating semantic representation
  claims.
  \item A final downstream replay showing a single non-aggregated HumanEval WS-D
  slice ($n=47$) that beats no-action and the stronger shuffled-action control by
  a few problems, while the configuration-bound gate closes the aggregate claim on
  MBPP-Plus saturation, missing standalone \code{p\_pass} scores, and broader
  representation and semantic gates.
  \item A \emph{released} anti-saturation falsification harness: a hard-negative
  pool generator and a three-baseline gate over a locked $\geq$100-problem slice.
  Its claim gate remains deliberately closed because no eligible slice has yet
  been scored.
\end{enumerate}

\section{Artifact and Claim Discipline}

\modelname{} is intentionally packaged as a research artifact. Each publishable
surface writes a schema-versioned report, manifest, checksum evidence, and
secret-scan result. Candidate code, generated patches, configs, checkpoints,
and provider outputs are treated as untrusted inputs. The model-scoring path
does not import, execute, or test-run candidate patches. Execution labels used
for training or benchmark construction are produced in bounded sandboxed data
build steps and then consumed as recorded artifacts.

The final paper-demo contract is deterministic. WS-D denotes the
mutation-distractor reranking benchmark: for each problem, a known-correct
reference solution is paired with lexically similar single-point AST mutants,
then labeled by the existing sandbox pipeline and shuffled so reranking has
pass/fail headroom. The v1.0 replay consumes checked-in v0.9 WS-D completion
labels and score rows for four slices: seed 42 and seed 1729 crossed with
HumanEval WS-D and MBPP-Plus WS-D. It covers 128 problem-slice rows and 768
candidate completions. These are $64$ unique problems ($47$ HumanEval and $17$
MBPP-Plus) scored under two seeds, at six candidates per problem; the count is
replay coverage, not independent problems. Replay mode records
\code{score\_source=replay\_existing\_scores}; it is not a fresh checkpoint
scoring run and not a live OpenRouter demo. The committed artifact id is
\code{demo\_report-e6fc06c328eed245}.

The release includes \emph{configuration-bound}, machine-readable claim gates.
The numeric thresholds were committed in the training configuration before the
runs (Section~\ref{sec:model}): collapse effective-rank ratio $\geq 0.20$
(achieved $0.388$/$0.406$), mutation-surprise AUC $\geq 0.65$ (achieved
$1.0$/$1.0$), retrieval Recall@1 lift over no-action $\geq 0.05$ (achieved),
downstream rerank pass@1 lift $\geq 3.0$ points over no-action (HumanEval WS-D
passes, MBPP-Plus WS-D $+0.00$ fails), and two required seeds. The gate prevents
retrofitting the claim to the data. It allows narrow HumanEval WS-D wording and
blocks aggregate coding-improvement wording because the cross-benchmark gate
does not pass.

\section{Model and Training}
\label{sec:model}

\modelname{} instantiates the transition contract of Equation~\eqref{eq:contract}
with a single module family of approximately $45$M parameters
(\code{TorchCodeTransitionModel}). A state encoder $E$ maps a bounded token
capsule (state length $1024$) to a latent $z \in \mathbb{R}^{256}$ using a
four-layer, eight-head Transformer with AdaLN-zero conditioning. An action
encoder $A$ maps the textual action (length $256$) to an action embedding, and a
predictor $P$ maps $(E(s_{\mathrm{before}}), A(a))$ to the predicted after-latent
$\hat z_{\mathrm{after}}$. Prediction targets are produced by an
exponential-moving-average copy $\bar E$ of the encoder (decay $0.99$), so the
objective predicts in latent space and never reconstructs target tokens, in the
style of feature-prediction JEPAs
\citep{assran2023selfsupervisedlearningimagesjointembedding,bardes2024revisitingfeaturepredictionlearning}.

The execution-substrate objective is a weighted sum of a latent prediction term,
an anti-collapse term, two action-use terms, an in-batch retrieval term, and two
supervised heads:
\begin{equation}
\label{eq:objective}
  \mathcal{L} =
  \big\|\hat z_{\mathrm{after}} - \bar E(s_{\mathrm{after}})\big\|_2^2
  + \lambda_{\mathrm{sig}}\mathcal{L}_{\mathrm{SIGReg}}
  + \lambda_{\mathrm{swap}}\mathcal{L}_{\mathrm{swap}}
  + \lambda_{\mathrm{inv}}\mathcal{L}_{\mathrm{inv}}
  + \lambda_{\mathrm{ret}}\mathcal{L}_{\mathrm{ret}}
  + \lambda_{\mathrm{pass}}\mathcal{L}_{\mathrm{pass}}
  + \lambda_{\mathrm{val}}\mathcal{L}_{\mathrm{val}},
\end{equation}
with weights $\lambda_{\mathrm{sig}}{=}0.09$, $\lambda_{\mathrm{swap}}{=}0.1$,
$\lambda_{\mathrm{inv}}{=}0.05$, $\lambda_{\mathrm{ret}}{=}0.05$,
$\lambda_{\mathrm{pass}}{=}0.5$, and $\lambda_{\mathrm{val}}{=}0.2$. SIGReg is the
sketched
isotropic-Gaussian (Epps--Pulley) regularizer of the LeJEPA family
\citep{balestriero2025lejepaprovablescalableselfsupervised,maes2026leworldmodelstableendtoendjointembedding};
it is the anti-collapse term. $\mathcal{L}_{\mathrm{swap}}$ penalizes predictions
under a mismatched action, $\mathcal{L}_{\mathrm{inv}}$ asks the latent transition
to retain action information, and $\mathcal{L}_{\mathrm{ret}}$ is an in-batch
InfoNCE-style retrieval term. The two auxiliary heads are a correctness head
trained with a class-balanced \code{p\_pass} BCE loss (positive weight $1.024$)
and an output-value cross-entropy head; we treat both as training-time auxiliary
signals, not as standalone downstream scores.

We optimize with AdamW (learning rate $3\times10^{-4}$, $\beta = (0.9, 0.95)$,
weight decay $0.1$) at an effective batch size of $256$ (micro-batch $64$,
gradient accumulation $4$) for $12{,}000$ steps with $500$ warmup steps, cosine
decay to zero, and gradient clipping at $1.0$, in \code{bf16} mixed precision on a
single A10G GPU. Every configuration is trained for two seeds, $42$ and $1729$.
At rerank time the model is used purely as a scorer: a candidate after-state
$s_{\mathrm{cand}}$ is embedded and ranked by its negated transition energy
$-\big\|\hat z_{\mathrm{after}} - E(s_{\mathrm{cand}})\big\|_2^2$ (lower latent
distance ranks higher). Candidate code is never imported, executed, or test-run
on the scoring path.

\paragraph{Configuration-bound acceptance gates.}
The training configuration fixes the acceptance thresholds \emph{before} the runs,
not after inspecting them. Collapse requires a predicted-latent effective-rank
ratio above $0.20$. Mutation surprise must exceed AUC $0.65$. Retrieval Recall@1
must be at least $0.05$ above no-action. A downstream slice needs pass@1 at least
$3.0$ points above no-action, and every gate requires two seeds for training
stability. These thresholds, rather than a post-hoc reading of the metrics,
decide which claims open.

\section{Data}
\label{sec:data}

The execution pack (\code{codelewm-execution-pack@v0.9.0-rc1}) contains $2{,}188$
sandbox-labeled execution transitions built from HumanEval ($1{,}882$ records)
and MBPP-Plus ($306$ records) completions, split $1{,}928 / 57 / 203$ into
train/validation/test. Pass/fail labels are near-balanced ($1{,}081$ passing,
$1{,}107$ failing; positive weight $1.024$); $26$ records were dropped for sandbox
timeouts. Labels are produced by a bounded, allowlisted sandbox-execution
data-build step and then consumed as recorded artifacts; sandbox execution is
never part of training or scoring. The HumanEval and MBPP-Plus WS-D reranking
slices used in Section~\ref{sec:rq3} are held out from training. Each WS-D
problem supplies six candidates ($1$ reference plus AST mutants), giving $47$
HumanEval and $17$ MBPP-Plus test problems per seed.

The two seeds vary only model initialization and training order; both are
evaluated on the \emph{identical} $47$-problem (HumanEval) and $17$-problem
(MBPP-Plus) WS-D sets with identical candidate pools. Cross-seed agreement is
therefore evidence of training stability, not of independent statistical
replication, and the per-seed confidence intervals are correlated because they
resample the same problems. We treat the configuration-bound two-seed requirement as a
stability check accordingly.

\subsection{RQ1: negative action-use evidence}

The v0.2 action-swap/inverse-action run directly tests whether action
conditioning beats no-action on held-out retrieval. It does not. Text-action
Recall@1 was 0.263 and MRR 0.370 on $1{,}000$ held-out retrieval examples, while
no-action reached Recall@1 0.441 and MRR 0.533; the result misses the configured
action-use gate by a wide margin. Exact-same-before, near-before, same-file,
action-cluster, edit-shape, and random action-contrast pools also failed to
show the required margin over no-action. Latent probes were unsupported for
semantic structure: lexical or metadata controls beat the latent views on the
available targets.

This is the main negative result. It means that the early edit-action signal
was not sufficiently action-discriminative. A commit message can describe a
change, but it often does not force the model to use the action rather than the
before-state. The no-action baseline is therefore not a nuisance baseline; it
is a first-class scientific control.

\subsection{RQ2: execution-substrate diagnostics}

The execution substrate changes the state/action/next-state signal from noisy
commit messages to deterministic execution triples. This improves training
health and diagnostic separability. By v0.9, retrieval lift over controls
passes on both seeds: Recall@1 is 0.2538 and 0.2731, while all listed retrieval
controls are below 0.024 Recall@1. Mutation surprise AUC is 1.0 on both seeds,
over 260 scored single-point mutation pairs; the broader semantic-decoy
categories have zero scorable aligned pairs, so this is narrow mutation surprise,
not broad semantic surprise. These training-health results have clear artifact
support. They do not, by themselves, prove downstream coding usefulness.

Representation claims remain closed. The v0.9 \code{passed} probe reaches
0.6552 and 0.6158 for \(\hat z_{\mathrm{after}}\), but no-action or before-state
controls are stronger. The \code{output\_magnitude\_bucket} target is evaluable
in v0.9 but tied with a direct \code{z\_after} control. Broad semantic surprise
also remains closed because the semantic-decoy categories have zero scorable
aligned pairs in the final pack.

which supplies a real but mismatched action (pass@1 $0.8936$ and $0.9149$), by
+8.51 and +6.38 points ($4$ and $3$ problems). Because shuffled-action dominates
no-action on exactly these slices, the win over shuffled-action, not over
no-action, is the binding result: the lift is not explained by the mere presence
of an action token. Against this strongest control the 95\% CIs are
$[0.00, 19.15]$ and $[0.00, 14.89]$, which \emph{include} zero, so even the open
slice is suggestive, not robust. The intervals are coarse: on $n=47$ the smallest
resolvable lift is one problem ($2.13$ points), the CIs are percentile bootstraps
without bias correction, and the two seeds reuse the same $47$ problems.
LLM-order is far weaker at pass@1 0.1489.

MBPP-Plus is the counterweight. On its $17$ problems, \modelname{}, no-action,
and lexical all rank a passing candidate first (pass@1 1.0000, i.e.\ $17/17$), so
the slice has zero headroom and is non-informative for any lift: the
$[0.00, 0.00]$ bootstrap interval reflects the absence of variation in a saturated
$17$-problem vector, not an equivalence result. This is exactly the configuration
the configuration-bound gate refuses to aggregate, so it closes the aggregate
downstream claim. Across the full evaluation (two benchmarks $\times$ two seeds
$\times$ four controls), we apply no multiple-comparison correction; the single
surviving open slice should be read as a hypothesis-generating result that cleared
a configuration-bound no-action gate, not as a multiplicity-controlled
confirmation. The evidence supports a narrow HumanEval WS-D result, not a claim
that \modelname{} generally improves patch ranking.

\section{Lessons}

\paragraph{No-action is a scientific baseline, not a convenience baseline.}
Many code transitions are sparse. Large portions of the after-state are
identical to the before-state, and many candidate completions can be ranked
using surface similarity. A world model must learn when the action changes
behavior, not merely when text resembles the prompt. The v0.2 failure shows
that weak action text can leave no-action stronger than the learned transition.

\paragraph{Substrate health is not downstream utility.}
The execution substrate yields healthier retrieval and mutation diagnostics,
but those diagnostics do not automatically imply useful patch ranking. This
distinction matters. Non-collapse, retrieval lift over controls, and surprise
separation are necessary health signals, not sufficient product claims.

\paragraph{Benchmark saturation can close an otherwise positive-looking result.}
The final WS-D MBPP-Plus pack is saturated on the available $17$ problems:
CodeLeWM, no-action, and lexical all choose passing candidates at rank 1 on both
seeds, so the slice has no headroom and cannot register a lift. This is not a
failure of the replay command, and it is not evidence of equivalence on a larger
benchmark; it is precisely the zero-headroom case the claim gate is designed to
refuse.

\paragraph{Representation claims require their own evidence.}
Healthy training diagnostics do not justify naming semantic latent axes.
Frozen probes must beat controls across targets and seeds, and semantic-decoy
surprise must have enough scorable aligned pairs. In the final evidence, those
conditions do not hold.

\section{Related Work}

\paragraph{Joint-embedding prediction.}
I-JEPA and V-JEPA learn feature predictions without pixel reconstruction
\citep{assran2023selfsupervisedlearningimagesjointembedding,bardes2024revisitingfeaturepredictionlearning}.
LeWorldModel studies stable end-to-end JEPA-style world modeling from pixels
\citep{maes2026leworldmodelstableendtoendjointembedding}. Anti-collapse
regularization is central to this family. \modelname{} adopts the LeJEPA-family
Sketch Isotropic Gaussian Regularizer (SIGReg), an Epps--Pulley-statistic penalty
that drives embeddings toward an isotropic Gaussian, rather than the
variance--covariance penalty of VICReg or the cross-correlation penalty of Barlow
Twins
\citep{bardes2022vicregvarianceinvariancecovarianceregularizationselfsupervised,zbontar2021barlowtwinsselfsupervisedlearning,balestriero2025lejepaprovablescalableselfsupervised};
SIGReg alone keeps the predicted-latent effective-rank ratio above the $0.20$
gate ($0.388$/$0.406$ across seeds).

\paragraph{Code modeling and execution signals.}
Pretrained code models such as CodeBERT, GraphCodeBERT, UniXcoder, and CodeT5
learn program representations or generation models from code and natural
language
\citep{feng2020codebertpretrainedmodelprogramming,guo2021graphcodebertpretrainingcoderepresentations,guo2022unixcoderunifiedcrossmodalpretraining,wang2021codet5identifierawareunifiedpretrained}.
HumanEval, MBPP, APPS, CodeNet, and EvalPlus-style benchmark extensions provide
candidate tasks and labels for coding evaluation
\citep{chen2021evaluatinglargelanguagemodels,austin2021programsynthesislargelanguage,hendrycks2021measuringcodingchallengecompetence,puri2021codenetlargescaleaicode,liu2023codegeneratedchatgptreally}.
Generated tests have also been used for reranking code generations
\citep{chen2022codetcodegenerationgenerated}. Execution-aware pretraining and
execution-trace work provide complementary signals for program behavior
\citep{zaremba2015learningexecute,ding2023tracedexecutionawarepretrainingsource,armengolestape2025iexecuteiunderstand}.
Architecturally, \modelname{} is an incremental port of LeJEPA-family
anti-collapse and EMA-target JEPA prediction to code-execution transitions. Its
methodological contribution is distinct: configuration-bound, machine-readable claim
gates with first-class no-action, lexical, and shuffled-action controls, so that
reranking claims are falsifiable before they are reported.

\paragraph{Reranking and scoring candidate code.}
A second line, directly relevant to how \modelname{} is used, ranks or filters
sampled candidate programs rather than generating them. Self-consistency and
sample clustering select among many decoded samples by agreement
\citep{wang2022selfconsistencyimproveschainofthought,li2022competitionlevelcodegenerationalphacode};
test-based reranking such as CodeT uses generated tests
\citep{chen2022codetcodegenerationgenerated}; learned critics and
likelihood-based reviewers score completions for functional correctness
\citep{le2022coderlmasteringcodegeneration,zhang2022coderreviewerrerankingcodegeneration};
and execution-based minimum-Bayes-risk decoding ranks candidates by executed
agreement \citep{shi2022naturallanguagecodetranslationexecution}. \modelname{} is
closest to energy-based scoring: it ranks candidate after-states by a latent
transition energy from a JEPA-style predictor, but, unlike test-, execution-, or
verifier-based rerankers, it never executes candidate code on the scoring path.
Our negative and saturation findings argue that such latent scorers must be
measured against no-action, lexical, and shuffled-action controls before any
reranking claim is credible.

\section{Limitations}

\begin{itemize}[leftmargin=1.5em]
  \item The final positive result is a slice result, not a broad benchmark
  result.
  \item The final paper demo replays checked-in v0.9 score rows over a single
  deterministic scoring pass per seed on the same problems. It is reproducible and
  manifest-backed, but it is not a fresh checkpoint scoring run, and we quantify
  only a paired problem-level bootstrap; artifact reproducibility is not
  robustness of the effect.
  \item The one open slice is small ($n=47$, a few problems of headroom) and its
  lift over the strongest control, shuffled-action, has a 95\% CI that includes
  zero; we report it as suggestive and non-aggregated, not as a robust effect.
  \item MBPP-Plus is saturated on its $17$ problems, so it has no headroom to
  measure any lift; this is non-informativeness, not measured equivalence.
  \item The representation probes do not support naming semantic dimensions.
  \item Broad semantic surprise remains blocked by scorable-pair coverage.
  \item Candidate code remains untrusted; the model-scoring path does not
  execute candidate patches.
  \item The results do not compare against large pretrained code models as
  generators. \modelname{} is a scorer/reranker artifact.
\end{itemize}

\section{Outlook: What Would Make the Next Claim Stronger?}

The next credible positive claim should be designed around gates that would
change the conclusion, not around a more polished demonstration surface. We see
five concrete directions.

\paragraph{Action-discriminative data.}
The training data should contain same-before and near-before candidate sets
where the action is necessary to choose the target. This directly attacks the
v0.2 no-action failure.

\paragraph{Non-saturated downstream labels.}
The next claim needs non-saturated downstream labels: at least $100$ public-safe
labeled tasks per target slice, with no-action and lexical controls below
saturation, and lift required over no-action, lexical, shuffled-action, and
LLM-order with confidence intervals excluding zero. We have already implemented
and released this instrument rather than merely proposing it (schema
\code{codelewm.downstream\_anti\_saturation\_report.v1}): a deterministic
public-safe hard-negative pool generator (no-action baits, partial fixes,
wrong-symbol or wrong-branch fixes, over-broad fixes, deterministic semantic
mutants, and LLM-generated valid candidates), LLM candidate-pack ingestion, a
\code{downstream-rerank}~\code{--hard-mode} scorer over ten baselines with
bootstrap lift CIs, and a \code{hard-downstream-publish} path with manifest,
secret scan, and claim audit. It applies a three-baseline gate: a slice opens a
positive claim only if \modelname{} beats no-action, lexical, \emph{and}
LLM-order on both pass@1 and MRR with all three bootstrap lift CIs excluding zero,
on a locked test slice of at least $100$ problems. No eligible locked slice has
yet been scored, so this gate currently \emph{remains closed}; we release the
harness as a falsification instrument, not as evidence of any new positive
result.

\paragraph{First-class calibrated scoring heads.}
If \code{p\_pass} is intended to support downstream ranking, it should be
serialized as a distinct score key in every downstream row, calibrated on held
out tasks, and evaluated separately from energy-derived CodeLeWM scores.

\paragraph{Representation probes tied to executable semantics.}
Semantic latent-axis claims should require probes that beat before-state,
no-action, lexical, and direct \code{z\_after} controls across seeds. Broad
semantic surprise should require enough scorable pairs to make the gate
meaningful.

\paragraph{Live utility only after offline gates.}
LLM patch demos are useful workflow evidence, but live utility claims should
come after offline gates pass. Candidate code should remain untrusted, and any
execution should stay inside explicit sandbox allowlists with manifests and
secret scans.

\section{Conclusion}

\modelname{} is a completed reproducible research artifact, not a broad coding
assistant. The artifact contract worked: datasets, checkpoints, reports,
claim gates, manifests, and scans can be regenerated and inspected. The
original action-use hypothesis did not work: no-action stayed stronger on
commit-edit retrieval. The execution substrate gave healthier model diagnostics
and a single narrow HumanEval WS-D downstream win that beats no-action and the
stronger shuffled-action control by a few problems, but MBPP-Plus saturation, a
shuffled-action lift whose confidence interval includes zero, and representation
blockers keep the public model-quality claim closed. The main contribution is
methodological: code world-model reranking claims should be published with
configuration-bound gates and their no-action, lexical, and shuffled-action
controls intact and, where the gate stays closed, with a released falsification
instrument rather than a louder claim.
